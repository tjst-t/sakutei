## #170：proxmox-vm の `ciupgrade`（§29.1）

- **背景**: Proxmox VE の cloud-init は既定で初回の起動にパッケージを更新する（VM の設定 `ciupgrade`、既定 1）。外への出口が
  無い網ではこれが時間切れになるまで起動が待たされる（手で確かめた例：0 にすると起動の完了までが約 185 秒から約 54 秒に縮んだ）。
  proxmox-vm にはこの設定を渡す口が無かった。
- **決定**（§29.1「proxmox-vm の cloud-init の初回のパッケージ更新（`ciupgrade`）」）:
  - フィールド `ciupgrade`（真偽値）。作るとき（作成・複製）に渡し、観測して違えば合わせる。反映と再起動の扱いは cloud-init の
    ほかのフィールドと同じ。
  - 既定は書かない：書かなければ Proxmox に渡さず、観測でも比べない（書かない人の振る舞いを変えない）。
  - 観測は設定の 0 / 1。書かれていなければ Proxmox の既定 1 を `true` と見る。
- **検証**: 単体（偽の Proxmox）と `make integration-proxmox` の「ciupgrade: false」段。
- **見送り**: 出口の無い網で起動が待たされないことの統合テスト（テストの網は外に出られる）。
